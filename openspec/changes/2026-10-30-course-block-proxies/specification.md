# 明确行为与验收口径

1. 实验目标物是彩色方块。蓝色表示可回收垃圾，红色表示有害垃圾，绿色表示厨余垃圾，黄色表示其他垃圾。每个方块有两个颜色面和四个图文面；图文面的例子见[视觉数据集说明](../../../docs/vision/COURSE_DATASET_NOTES.md)。
2. F1 对每个可见目标输出方框、业务类别、置信度和中心像素坐标；同一张图中出现多个方块时分别标注。颜色与业务类别的关系在标注、训练、推理、事件和 Web 显示中保持一致。
3. F2 将识别到的方块投放到对应颜色区域。安全门禁、坐标边界、重试和急停规则沿用现有基线。
4. 206 张课程图片属于未标注原始候选样本。经去重、质量检查和逐框标注后，可计入数据集；未标注图片不得直接作为已完成的数据集或模型评估证据。每类至少 300 张、总计至少 1200 张以及 7:2:1 划分保持不变。
5. 验收报告应注明“彩色方块模拟垃圾分类”。真实垃圾上的泛化能力须另行采集、训练和测试，不能由方块测试结果推断。

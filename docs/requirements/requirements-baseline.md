# 需求基线（v0.1）

## 目标与主链路

系统在固定桌面工作区内完成垃圾目标的视觉识别、坐标换算、机械臂抓取和分类投放，并记录完整事件供 Web 看板查询。

`Camera → DetectionResult → TargetPose → PickTask → PickResult → SortEvent → Dashboard`

## 功能与验收

| ID | 功能 | 验收标准 |
|---|---|---|
| F1 | 视觉识别 | mAP@0.5 ≥ 0.80；每类 Recall ≥ 0.75；单帧推理 P95 ≤ 150 ms；输出类别、置信度、中心像素坐标。 |
| F2 | 任意位置分拣 | 在 3×3 网格的 10 个未预置位置中，一次成功率 ≥ 85%；允许 1 次重试后的完成率 ≥ 95%；单点周期 P95 ≤ 15 s；越界拒绝率 100%。 |
| F3 | 管理看板 | 提供总览、实时事件、分类统计、异常日志；事件写入至展示延迟 P95 ≤ 1 s；字段完整率 100%。 |
| F4 | 兜底机制 | 识别失败、坐标越界、抓取失败、通信超时、部署失败均有可观测响应；演示成功率 ≥ 80%（10 次中至少 8 次）；故障识别至降级 ≤ 1 s；不安全动作 0 次。 |
| E1 | 手势互动 | 特定手势触发安全区内预设动作并回安全位；正确率 ≥ 90%；触发延迟 P95 ≤ 1 s；动作越界 0 次；10 秒冷却。 |
| E2 | 语音控制 | “帮我分类”触发一次完整分拣；4 人 × 2 环境 × 5 次共 40 次有效指令，启动比例 ≥ 90%，响应 P95 ≤ 2 s；20 条无关语音的误触发率 ≤ 5%。 |

## 范围边界

1. 不做动态传送带连续追踪与分拣。
2. 不做任意高度、堆叠或严重遮挡下的三维抓取；只处理标定的固定高度平面。
3. 不处理透明、柔性、液体及超出夹爪能力的物体；实验物体须先通过尺寸、质量和可夹持性检查。

## 安全门禁

控制层在下发动作前必须同时满足：

- `workspace_ok=true`；
- `task_id` 全局唯一，重复请求只能返回已有任务状态；
- 1/2/3/4/6 号舵机在 0°–180°，5 号舵机在 0°–270°；
- 目标点位于有效工作区；
- 急停已经解除，机械臂不存在未清除故障。

任一门禁不满足，控制层拒绝执行并写入错误码。

## 数据与硬件约束

- 视觉数据集不少于 1200 张，四个类别各不少于 300 张，覆盖不同光照、角度、距离和部分遮挡；按 7:2:1 划分训练、验证、测试。
- 标注由第二人抽检 20%；差异超过 5% 时进行全量复核。
- Atlas 200I DK A2：4 核 CPU、4 GB 内存、8 TOPS INT8。
- 6 舵机状态可回读、精度 ≤ 1°、堵转 3 秒保护；UART 115200，使用 Arm_Lib；K2 急停可用。
- “抓取成功”必须同时通过舵机状态回读与抓后视觉复核。

## 变更规则

本文件是需求基线。修改任何验收数字、范围边界、接口字段或安全门禁时，必须先按 [OpenSpec 变更流程](../../openspec/README.md) 创建变更记录，并在 Pull Request 中说明影响范围。

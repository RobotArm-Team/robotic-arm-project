# 彩色方块数据集标注规范

## 适用范围

本规范用于课程“垃圾分拣小助手”的彩色方块检测数据。方块模拟垃圾类别，不用于声明对真实垃圾具有识别能力。

## 类别与固定 ID

| ID | 训练标签 | 方块颜色 | 业务类别 | 图文面示例 |
| --- | --- | --- | --- | --- |
| 0 | `recyclable` | 蓝色 | 可回收垃圾 | 书本、易拉罐、旧书包、报纸 |
| 1 | `hazardous` | 红色 | 有害垃圾 | 过期化妆品、过期药品、注射器、废旧电池 |
| 2 | `kitchen` | 绿色 | 厨余垃圾 | 西瓜皮、鸡蛋壳、鱼骨、苹果核 |
| 3 | `other` | 黄色 | 其他垃圾 | 核桃、卫生纸、烟蒂、一次性筷子 |

标签 ID 必须在标注、YOLO 类别文件、推理结果、ROS2 任务事件和 Web 显示中保持一致。

## 逐框规则

1. 图中每个可见的大面积实色面各画一个矩形框，即使同一图片出现多个方块也分别标注。
2. 方框只覆盖蓝、红、绿、黄的大面积实色面并尽量贴边；不包含图文侧面、桌面、阴影、机械臂或垃圾桶区域。
3. 标签只按实色面颜色确定；仅露出图文面而看不到可可靠定位的实色面时，本轮基础数据集不标注。
4. 实色面被部分遮挡但仍能可靠判断边缘和类别时保留标注；类别或边缘无法可靠判断时不标注，并记录为待复核样本。
5. 模糊到无法判断方块边缘或类别、严重过曝/欠曝、没有目标方块的图片不进入训练集，保留在原始目录并写入剔除原因。

当前规则与课程平台示例保持一致，目标是完成基于颜色面的方块分类和定位。框住整个方块并不能保证模型学会图文面；若后续需要“任意面识别”，必须另行采集彩色面不可见、四个图文面分别朝向相机的样本，并建立独立测试集。

## 数据划分与质量检查

1. 先对原始图片去重和质量筛选，再开始划分。
2. 按图片划分训练、验证、测试集，比例为 7:2:1；同一连续拍摄序列或近似重复图片不得跨集合。
3. 每类至少 300 张含该类方块的有效图片；同时统计每类目标框数，不能只报总图片数。
4. A 对至少 20% 的标注进行抽检；差异超过 5% 时复核全部标注。
5. 测试集在训练冻结前确定，只用于最终评估，不参与调参或数据增强。

## 本轮执行顺序

1. 标注 `data/raw/course-blocks/images/` 中的 206 张课程候选图片。
2. 输出每张图片的 YOLO 标注、质量状态和按类统计表。
3. 依据每类有效图片数计算补采缺口。
4. 在实际相机与机械臂上完成标定后，按缺口补采不同位置、角度、距离、光照和部分遮挡的样本。

课程资料与盘点结论见[课程数据集与训练任务核对](COURSE_DATASET_NOTES.md)。

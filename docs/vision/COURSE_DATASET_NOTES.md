## 课程任务原意

第三阶段“任务3：相机校准与数据采集”要求先完成机械臂相机标定。示例将十字标定板区域透视变换为 640×480 图像，保存 1、2 号舵机角度及边缘检测阈值到 `XYT_config.txt`，并将四个轮廓顶点保存到 `dp.bin`。采集时复用这些参数，使相机位置和取景区域保持一致。

课程实验用四种颜色的积木代表四类垃圾。每个方块的两个面显示颜色，其余四个面分别印有该类别的图片与名称。课程任务要求每种颜色采集 100 张，共 400 张：把积木依次放入采集区域，点击“保存图片”按钮；示例用 `data_collect_idx.txt` 维护图片编号。这里的 400 张是课程采集目标，不是资料页已提供的图片数量。

| 方块颜色 | 业务类别 | 方块图文面的例子 |
| --- | --- | --- |
| 蓝色 | 可回收垃圾 | 书本、易拉罐、旧书包、报纸 |
| 红色 | 有害垃圾 | 过期化妆品、过期药品、注射器、废旧电池 |
| 绿色 | 厨余垃圾 | 西瓜皮、鸡蛋壳、鱼骨、苹果核 |
| 黄色 | 其他垃圾 | 核桃、卫生纸、烟蒂、一次性筷子 |

颜色和图文面由组长 B 于 2026-10-30 根据实物补充说明；课程[项目需求说明](http://10.126.59.136:30080/course/previewCourseProject/c17d2b20c3b84c898d74796a25be9c02/1)与第三阶段“目标描述及任务安排”“任务5：任意位置分拣”均明确以彩色积木完成“垃圾分拣小助手”，投放到对应颜色的“垃圾桶”。

第三阶段“任务4：训练积木检测模型”要求把采集的图片放在英文路径下，选择检测任务，用矩形框框住目标并填写类别标签。课程示例使用 Ascend AI Devkit Model Adapter 做迁移训练，生成 `infer_project.tar.gz`，随后在平台转换为 `yolov5s_bs1.om` 并部署到 Atlas 200 DK A2 推理。这些工具和模型名称属于课程示例流程。

## 与本仓库 F1 基线的关系

| 项目 | 课程示例 | 本仓库当前基线 |
| --- | --- | --- |
| 识别对象 | 四种彩色积木，模拟四类垃圾 | 同样以四种彩色方块作为四类垃圾的实验代理；真实垃圾识别不在本次验收内 |
| 图像数量 | 每类 100 张，共 400 张 | 每类至少 300 张，共至少 1200 张 |
| 标注 | 检测任务的矩形框与类别名 | 需形成可复现的检测标注和训练/验证/测试划分 |
| 模型路径 | Model Adapter 迁移训练，示例输出 YOLOv5s OM | 计划使用 YOLOv8，并按目标设备验证部署方式 |
| 图像处理 | 标定后透视变换到 640×480 | 应与 C 的标定输出和后续像素坐标契约保持一致 |

课程示例提供采集、标定、矩形框标注和设备推理的操作参考；F1 的交付数量与模型指标仍以仓库的[需求基线](../requirements/requirements-baseline.md)为准。模型在方块上的效果不能直接作为识别真实垃圾的证据。若最终硬件无法运行计划中的模型，需要用设备实测结果讨论调整模型方案，并同步接口、测试和需求记录。

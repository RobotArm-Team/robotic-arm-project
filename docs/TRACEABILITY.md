## 使用规则

1. 每个 Issue 正文必须引用本表的需求编号。
2. 每个 PR 描述必须使用 `Closes #<issue>` 或链接对应 Issue。
3. 证据文件写清版本、日期、环境、操作者和原始事件 ID。
4. 未经 PR 合并的材料不算最终交付物；未关联需求的 PR 不计入个人贡献核定。
